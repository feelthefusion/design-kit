## Design Kit notes

- In repos using the Design Kit, the file is `docs/DESIGN.md`, or an existing root `DESIGN.md` if there is one. **design-direction** covers what goes in it (colour, type, spacing, radius, motion, icon set, voice) and how to seed it from Marketing Kit's `.agents/brand-context.md`.
- The Design Kit gate treats the front matter as normative: rendered colours and fonts, and literal values in code, must map to its tokens.
