> **Design Kit overlay (fix-and-rerun).** In this kit the default mode is **fix-and-verify**, not audit-only: when you find a defect, fix it at its root cause, re-render, and re-run the same check until it is clean. Do not stop at a report. The kit's gate (`design-gate`, run by `verify.sh`) runs this skill's `visual_layout_audit.mjs --fail-on-warning` at 375/768/1440 on the main routes together with the dead-button, fixed/sticky-overlap, alignment, brand and type checks. Any finding blocks "done". Keep the upstream rules against evading the detector: never hide overflow, shrink all type, rename selectors or delete a feature to get to green.
>
> Routing in this kit: visual direction and tokens → **design-direction** (writes `docs/DESIGN.md`). Building the look → **Taste** (`design-taste-frontend`, Skill Starter Kit). Browser driving and screenshots → **browser-verify** (Skill Starter Kit). Critique and polish passes → **impeccable**. Mobile speed → **core-web-vitals**.
